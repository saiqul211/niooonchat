# ADR-002: Strict Dark Mode & English-Only UI Design System

## Status
Accepted

## Context
A consistent, high-contrast, modern visual aesthetic is required across web and mobile platforms.

## Decision
1. The app design strictly adheres to Dark Mode (`bg-black`, `bg-neutral-950`, `text-neutral-100`). No light theme toggles or light backgrounds are implemented.
2. All UI strings, component labels, button texts, error messages, and toasts are strictly written in English.

## Consequences
- **Positive:** Sleek unified look, high contrast readability, and consistent localization across all screens.
- **Rules:** Never hardcode non-English strings or introduce white/light background canvases.
