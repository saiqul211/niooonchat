# ADR-003: Chatted-Only Search Scope & Exact Username Direct Chat Navigation

## Status
Accepted

## Context
Privacy is paramount in Niooon Chat. Users should not have their accounts browsable or scraped via generic public search lists or typing-triggered auto-suggestions.

## Decision
1. The search list only displays contacts with whom the user has already sent or received messages.
2. Initiating a new conversation with an un-chatted user requires typing the exact `@username` and triggering search, which queries the database for an exact match and automatically navigates directly to `#/chat?user=:username`.
3. No public directory browsing or auto-complete suggestions are allowed for non-chatted users.

## Consequences
- **Positive:** Maximum privacy protection against spamming, scraping, and unsolicited directory browsing.
- **Rules:** Never query all users from `profiles` without filtering by chatted partner IDs or exact username match.
