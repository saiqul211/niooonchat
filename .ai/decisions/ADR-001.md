# ADR-001: Supabase as Core Backend & Realtime Engine

## Status
Accepted

## Context
The application requires authenticated user management, persistent profile storage, fast direct messaging, and instant realtime message dispatch without running complex custom socket server infrastructure.

## Decision
Adopt Supabase (PostgreSQL + Supabase Auth + Supabase Realtime) as the primary backend database and real-time synchronization layer.

## Consequences
- **Positive:** Built-in JWT authentication, Row Level Security (RLS) policies at the database level, and zero-configuration WebSocket live changes.
- **Rules:** Every schema migration or policy modification must be explicitly verified and adhere to project permission rules.
